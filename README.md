# Разбор входящих

Демо-сервис: лента обращений выдуманной компании «Кислородик» и разбор своего запроса. Jev решает, что это за обращение и куда его отправить, Claude пишет черновик ответа. Бэкенд целиком в n8n Cloud, фронтенд — статическая страница на GitHub Pages.

Сделано как пример проекта к отклику в BRANDFREE. Компания, обращения и люди выдуманы.

## Что умеет

- **Лента:** 45 выдуманных обращений за две недели — отзывы с маркетплейсов, оптовики, блогеры, кандидаты, внутренние согласования, спам. Сводка дня и фильтр по отделам.
- **Мой разбор:** свой текст или кнопка-пример проходит четыре этапа — правила, решение Jev, маршрут, черновик. Видны вероятности, пороги и время каждого шага.
- **Отбивки:** слишком короткий текст, не по теме, спам, попытка взлома, неясный отдел, превышение лимитов — каждая с объяснением и цифрой Jev.
- **Доступ по приглашениям:** персональная ссылка с кодом, срок и лимит разборов, уведомление автору в Telegram при первом открытии и с каждого нового устройства.

## Как устроено

```
Браузер (GitHub Pages)                n8n Cloud
  POST /inbox/feed      ───────▶  Inbox · Лента      ─┐
  POST /inbox/classify  ───────▶  Inbox · Разбор     ─┼─▶ Inbox · Проверка доступа ─▶ Inbox · Уведомление (Telegram)
  POST /inbox/draft     ───────▶  Inbox · Черновик   ─┘
                                  Inbox · Выдать доступ (форма с Basic Auth)
                                  Inbox · Очистка (каждую ночь, обращения старше 30 дней)
                                  Data Tables: приглашения, устройства, лента, обращения, примеры
```

- **Почему POST-формой.** Все запросы — `application/x-www-form-urlencoded` с полями `invite`, `device` и данными запроса, без своих заголовков. Браузер не делает предварительный CORS-запрос, а CORS вебхуков ограничен адресом страницы.
- **Почему две нейросети.** Jev (TypeSafe AI) отвечает на типизированные вопросы вероятностями за 0,2–0,6 с — это решения с цифрой, которую можно сравнить с порогом. Claude пишет текст и подключается только для обращений, ушедших в отдел, поэтому мусор и попытки взлома до генеративной модели не доходят.
- **Пороги.** Обращение ниже 40% — отбивка, 40–70% или категория ниже 50% — ручной разбор, выше 70% — отдел. Попытка взлома от 50% — стоп, подделка от 60% — метка «Юристы».
- **Запасной путь.** Если кредиты нейросетей кончились или превышен дневной лимит, кнопки-примеры отдают записанные ответы с пометкой «запись».

Контракты вебхуков и схема таблиц — в [docs/architecture.md](docs/architecture.md). Экспорт workflow — в [n8n/](n8n/).

## Запуск локально

```bash
npm install
npm run dev
```

Страница откроется на `http://localhost:5173`. Для живой ленты нужен код приглашения: `http://localhost:5173/?invite=<код>`. CORS вебхуков пропускает `localhost:5173` только на время разработки.

```bash
npm test
npm run build
```

`npm run build` сначала собирает `src/styles/tokens.css` из `design/tokens.json` — копии токенов дизайн-системы.

## Как поднять свою копию бэкенда

1. Импортируйте файлы из `n8n/` в свой n8n.
2. Создайте Data Tables из [docs/architecture.md](docs/architecture.md) и загрузите `data/seed.json` и `data/examples.json`.
3. Подключите учётные данные: Telegram-бот, Basic Auth для формы, TypeSafe AI и Anthropic (или встроенные кредиты n8n Cloud).
4. Поменяйте `API_BASE` в `src/config.ts` на адрес своих вебхуков.
